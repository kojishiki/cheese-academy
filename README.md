## ② 制作サイトの説明
チーズ職人養成学校の受講生募集サイトです。

## ③ 工夫した点・こだわった点
- 卒業後のキャリアについてイメージできる内容を追加しました。
- 見本サイトの構成をベースに、卒業生に関するオリジナルコンテンツを追加しました。

## ④ 難しかった点・次回トライしたいこと

### 難しかった点
- COURSEの写真と文章の位置調整
- ACCESSの文章の位置調整
- CONTACTのフォームの位置調整

### 次回トライしたいこと
- ACCESSに実際のGoogleマップを組み込みたい。
- 画像のスライド機能を追加したい。
- マウスを合わせると画像が動く機能を試したい。

## ⑤ 備考・感想
最初はオリジナルサイトの制作を試みましたが、思うように進まず、断念して見本通りに制作することにしました。

ただ、それだけでは少し物足りなかったので、卒業生に関するコンテンツを追加してみました。

今回は少しだけでしたが、自分のアイデアやイメージを形にしているときが一番面白かったです。
